# HERMES HF PWAS Analysis

This folder contains scripts for running the PWAS/S-MiXcan workflow on the
HERMES HF GWAS summary statistics using the existing heart protein weights.

The workflow is independent from the HERMES DCM workflow and writes to separate
HF result and figure folders.

## Run The Workflow

Run from the repository root.

### Option A. Run one file at a time

#### 1. Liftover HERMES HF GWAS from hg19 to hg38

Input:

```text
Heart/HERMES_HF/FORMAT-METAL_Pheno1_EUR.tsv.gz
Heart/Data/1000g_b38_snpIDs.txt
```

Script:

```bash
/opt/anaconda3/bin/python Analysis_code/HERMES_HF/1_liftover_hermes_hf_gwas.py
```

Output:

```text
Heart/HERMES_HF/FORMAT-METAL_Pheno1_EUR_hg38_rsid.tsv.gz
```

The liftover script keeps the input `rsID` by default and skips the slower
1000G rsID replacement scan. If hg38 1000G rsID replacement is needed, add:

```bash
--add-1000g-rsid
```

The current step 1 script is optimized for this HF file:

- default chunk size is `1,000,000` rows
- liftover is cached by unique `chr:pos_b37` within the run
- existing input `rsID` is retained by default
- the slower 1000G rsID annotation scan is optional

For the full `396 MB` GWAS file, expect roughly `10-30` minutes for step 1 on
this machine when running without `--add-1000g-rsid`.
